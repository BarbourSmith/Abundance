# Standalone G-code Generator Examples

This repository includes two standalone examples for generating G-code from STL files using different approaches.

## Examples Overview

### 1. Minimal G-code Generator (`minimal-gcode-generator.html`)
**Recommended for most users** - A truly minimal, self-contained example that demonstrates basic G-code generation principles.

### 2. Advanced G-code Generator (`gcode-generator-example.html`)
Uses the full Abundance/Kiri:Moto engine for professional-grade G-code generation.

---

## Minimal G-code Generator (Recommended)

**File**: `minimal-gcode-generator.html`

### Overview
A lightweight, educational example that demonstrates the core concepts of STL-to-G-code conversion. Perfect for understanding the basics or integrating into other applications.

### Features
- **Self-contained**: No external dependencies, runs directly in browser
- **Educational**: Clear, commented code showing G-code generation principles  
- **Responsive**: Works on desktop and mobile devices
- **Real-time feedback**: Progress indicator and G-code preview
- **Configurable**: Adjustable passes, tool size, feed rates, and cut depth

### Usage

#### Option 1: Direct Browser Access
1. Start the development server: `npm start`
2. Navigate to: `http://localhost:4444/minimal-gcode-generator.html`

#### Option 2: Standalone File
The HTML file can be opened directly in a browser (no server required).

### Parameters
- **STL File**: ASCII STL format supported
- **Number of Passes** (1-10): Controls cutting depth per pass
- **Tool Size** (mm): Cutting tool diameter (default: 6.35mm / 1/4")
- **Feed Rate** (mm/min): Cutting speed (default: 1500)
- **Cut Through** (mm): Extra depth for complete cuts (default: 1.5mm)

### Generated G-code Features
- Standard G-code headers (G21, G90, G17)
- Safe height movements for tool safety
- Spindle control (start/stop)
- Multiple pass cutting with correct depth calculations
- Rectangular outline cutting path
- Proper program termination

### Example Output
```gcode
; Generated by Minimal G-code Generator
; Tool Size: 6.35mm, Passes: 2
G21 ; Set units to millimeters
G90 ; Absolute positioning
G0 Z15.00 ; Move to safe height
M3 S1000 ; Start spindle

; === Pass 1 of 2 ===
G0 X-3.175 Y-3.175
G1 Z4.250 F750    ; Plunge
G1 X13.175 F1500  ; Cut outline
G1 Y13.175
G1 X-3.175
G1 Y-3.175
G0 Z15.00         ; Retract

; === Pass 2 of 2 ===
[...continues for each pass...]

M5 ; Stop spindle
M30 ; Program end
```

## Advanced G-code Generator

**File**: `gcode-generator-example.html`

### Overview
Uses the full Abundance platform's Kiri:Moto engine for professional CAM operations. More complex but provides industry-standard G-code generation.

### Features
- **Professional CAM**: Uses proven Kiri:Moto engine
- **Advanced toolpaths**: Optimized cutting strategies
- **Complex geometries**: Handles intricate STL files
- **Multiple operations**: Roughing, finishing, etc.

### Usage
1. Start the development server: `npm start`
2. Navigate to: `http://localhost:4444/gcode-generator-example.html`
3. Wait for the engine to initialize (may take 10-30 seconds)

### Note
This example requires the full Abundance application stack and may take longer to load due to the WebAssembly engine initialization.

## Technical Implementation

### Minimal Generator Approach
1. **STL Parsing**: Basic ASCII STL vertex extraction
2. **Bounds Calculation**: Automatic part size detection
3. **Tool Offset**: Calculates cutting path outside part boundary
4. **Pass Planning**: Divides total depth by number of passes
5. **Path Generation**: Creates rectangular outline toolpath
6. **G-code Output**: Standard format with safety features

### Advanced Generator Approach
1. **Engine Loading**: Initializes Kiri:Moto WebAssembly engine
2. **STL Processing**: Full 3D mesh analysis
3. **CAM Operations**: Professional toolpath generation
4. **Optimization**: Advanced cutting strategies
5. **Export**: Industry-standard G-code output

## Limitations & Considerations

### Minimal Generator
- **STL Format**: ASCII STL only (most common format)
- **Toolpath**: Simple rectangular outline cutting
- **Operations**: Outline cutting only (no pocketing, drilling, etc.)
- **Complexity**: Best for simple parts and educational use

### Advanced Generator  
- **Loading Time**: Requires WebAssembly engine initialization
- **Complexity**: Full CAM application dependencies
- **Size**: Larger memory footprint

## Example Workflow

1. **Prepare STL**: Export your 3D model as ASCII STL
2. **Choose Generator**: 
   - Minimal: For simple parts and learning
   - Advanced: For complex parts and production
3. **Configure Parameters**:
   - More passes = shallower cuts = smoother finish
   - Adjust tool size to match your actual cutter
   - Set feed rate appropriate for your material
4. **Generate G-code**: Process and download the file
5. **Verify**: Check the generated toolpath before machining

## Support & Troubleshooting

### Common Issues
- **File won't load**: Ensure ASCII STL format
- **Generation fails**: Check parameter ranges
- **Browser compatibility**: Use modern browsers with WebAssembly support

### Performance Tips
- Larger files take longer to process
- More passes require more computation
- Complex geometries may need additional time

The minimal generator is recommended for most users as it provides a clear, educational implementation of G-code generation principles while being fast and reliable.
