Input Atom Color Coding Demo

This demonstrates the new color coding system for input atoms in Abundance. Different input types now have distinct colors for visual differentiation:

Default/Unknown

Default

Fallback color

Implementation Details

  • Colors are applied when input atoms are in the "ready" state and not selected
  • Status-based colors (error, waiting, processing) take precedence over type colors
  • Selected atoms maintain their existing selection appearance
  • Colors are designed to be light and provide good contrast with dark text
  • All colors are visually distinct from each other for accessibility
